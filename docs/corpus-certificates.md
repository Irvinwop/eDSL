# Named final-ELF certificates

`EDSL.Corpus.Certificate` connects three proof obligations: the complete literal
file and unique named function extent pass the ELF checker; the exact selected
bytes satisfy an independently registered task; and a useful current-resource
call exists at that function's actual loaded address. A certificate's
`useful_execution` theorem establishes that joint nonvacuity. Its `resource`
theorem applies the registered all-AF result, actual return hook and every-prefix
resource policy to every admitted call.

`LoadedCall` records fresh checked installation, the registered resource
precondition and actual entry. Its current memory may differ from installation
outside the selected text. `TextUnchanged` explicitly requires the selected
readable bytes and execute permissions to persist; admission alone cannot
establish that later condition. Registered resource preconditions independently
require current executable code and caller authority. A certificate is not an
assertion that an arbitrary native process has that authority.

`ELFResources` transports a supplied readable caller stack through fresh image
installation, preserving complete prior cells and permissions. It constructs
`CallResources.Domain.Facts` without rerunning the function or assuming its
result. The domain declares a new modeled ownership registry and issues code
and caller-slot loans using the existing borrowing API. It neither authenticates
native principals nor transports preexisting native loans.

The v1 comparison adapter shares one complete literal file and metadata proof
per compiler. `V1.Comparisons.certificate compiler operation` composes those
proofs, actual-address resources and the common VCG comparison family. New
functions do not need another instruction interpreter, per-step proof or command
line driver. Independent specifications and any necessary loop invariants remain
proof obligations.

The default GCC ENDBR64 bytes remain present. The fixed sequential target
assumes long mode, CET indirect-branch tracking and shadow stacks disabled, and
multi-byte NOP support. The registered profile also assumes stable modeled RAM,
valid caller/code resources and absent asynchronous interference. The theorem
covers the modeled callable machine function. It establishes no native Linux
startup, dynamic relocation, source-language preservation, physical processor
refinement or whole-kernel safety.

The shared comparison proof separately establishes exactly five retired modeled
instructions for GCC and four for Clang, including RET and GCC's ENDBR64, and
one ordered STACK8 operand read. These are exact counts of these executions;
they establish neither globally minimum instruction sequences nor physical
micro-operation counts or execution time.

Certification measurements must bind complete literal files to the checked-in
frozen ELFs and replay the composed proof. Symbol extraction, native tests,
CFG acceptance and source digests remain separate evidence. The immutable v1
initial reports remain historical baselines; subsequent reports belong outside
`corpus/v1/`. The primary function numerator requires both compiler profiles.

The later [scalar constructor](corpus-scalar-certificates.md) generalizes the
actual-address resource and registration bridge for additional fixed scalar
tasks, including modular addition. The comparison family and its original
measurement remain separate, reproducible evidence.
