# Local analysis records

This directory contains an empty [example record format](index.example.json)
for recording property violations during local analysis. It is not a public
vulnerability database or an automated scanner.

Actual records belong in the ignored `index.json`, `records/`, or `private/`
paths. Keep third-party findings and identifying evidence out of Git and CI.
See the [security policy](../SECURITY.md) and
[evidence guidance](../docs/findings.md).
